# **🚀Typing Master🚀** - Тренажер печати


Эта программа-игра очень полезна в современном мире, где печать на клавиатуре стала неотъемлемой частью жизни. Данная игра поможет вам в игровой форме натренировать данный навык. Слова движутся по экрану, и игрок должен успеть их ввести до того, как они достигнут правого края.

<a id="компиляция"></a>

## Win
### 🔧 Компиляция

```
gcc main.c game.c ui.c platform_win.c words.c stats.c -o typing_master.exe -std=c99
```

### ✅ Запуск 

```
typing_master.exe
```
## Linux
### 🔧 Компиляция

```
gcc ./main.c ./game.c ./ui.c ./platform_ncurses.c ./words.c ./stats.c -o ./typing_master -lncurses
```

### ✅ Запуск 

```
./typing_master
```

<a id="управление"></a>
## ✨ Управление

* **EN Буквы**: Ввод слов

* **Пробел**: Подтверждение слова

* **Backspace**: Удаление символа

* **ESC**: Назад

* **Цифры 1-4**: Выбор пунктов меню
